Storytecno

Storytecno is a YouTube channel about the stories behind technological inventions: processors, embedded systems, artificial intelligence, the internet and more.

Storytecno Studio is the channel's internal tool that produces videos and publishes them to the Storytecno YouTube channel using YouTube API Services. It also displays the channel's own YouTube Analytics metrics.
